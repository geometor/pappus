Using This Edition¶

Reader’s Guide to the GEOMETOR Interactive Digital Codex of Pappus’s Synagoge

Welcome to the GEOMETOR Digital Scriptorium edition of Pappus of Alexandria's Synagoge (Μαθηματικὴ Συναγωγή). This edition unites Friedrich Hultsch’s critical Weidmann Greek text, complete scholarly English translations, and 100% exact symbolic models of classical and projective geometry.

1. Synchronized Reading Tracks¶

The Synagoge Book Codex features four synchronized reading tracks accessible directly in the header bar of each proposition page:

  • English (``-en``): Fresh scholarly translation of Pappus’s Greek text, wired with interactive vector diagrams and mathematical commentary.

  • Greek (``-el``): Verbatim polytonic Greek text from Friedrich Hultsch's critical edition (1876–1878), keyed by Hultsch page and proposition numbering.

  • Summary (``-summary``): Structural summaries mapping proposition goals, algebraic invariants, and lemma dependencies.

  • Notes (``-notes``): Philological commentary, historical reception from Commandino (1588) to Heath (1921), and cross-corpus links.

2. Primary-Source Folio Milestones¶

  • Hultsch Volumes & Pages: Clickable marginal markers link directly to Hultsch’s three-volume Weidmann edition (Codex Vaticanus Graecus 218).

  • Commandino (1588): Loci correlate with the Renaissance Latin editio princeps.

3. Theorems & Exact Symbolic Models¶

Every diagram is generated dynamically with zero floating-point approximations over \(\mathbb{Q}\) and \(\mathbb{Q}(\phi)\):

  • Geometric Elements (``:g:``): Hovering or clicking points, lines, circles, or conics in the text highlights matching elements in the interactive SVG graphic.

  • Mathematical Invariants (``:eq:``): Formal verification of cross-ratio invariance \((A, B; C, D) = (A', B'; C', D')\), harmonic division \(-1\), Pappus line collinearity, and honeycomb area ratios.

  • Euclidean Justifications (``:just:``): Explicit deductive links cite dependencies in Euclid’s Elements (Heath 1926).

4. Full-Text Search with In-Page Highlighting¶

  • The built-in search engine indexes polytonic Greek technical terms, Latin terminology, and modern mathematical concepts.

  • Query URLs append ?highlight= to highlight matched terms directly inside the chapter text.

5. Categories, Tags & Collection Views¶

  • Explore projective theorems, arbelos chains, means, and isoperimetry through structured taxonomy facets.

  • Switch between Cards, Banners, and List views on collection pages.

6. Scholarly Hover Cards & Dark Mode¶

  • Prosopography (``:person:``): Hover cards provide biographical dates and historical contexts for all 26 figures.

  • Bibliography (``:cite:``): Citations display full bibliographic records and public-domain library links.

  • Glossary (``:term:``): Hover over technical terms for multilingual definitions.

  • Theme Toggle: Light and Dark reading modes.

Synagoge Classical Constructions (Books III, IV, V & VIII)¶

from geometor.pappus import (
            PHI,
            construct_pappus_arbelos_chain,
            construct_pappus_area_theorem,
            construct_three_means,
            verify_arbelos_chain_symbolic,
            verify_honeycomb_isoperimetry,
            verify_pappus_area_symbolic,
        )

        # Book III: Arithmetic, Geometric, and Harmonic Means in one semicircle
        means = construct_three_means(9, 16)
        print(means.arithmetic_mean, means.geometric_mean, means.harmonic_mean)  # 25/2, 12, 288/25
        print("Harmonic tangent CR (A, C; D, T):", means.harmonic_cross_ratio)   # -1
        print("Golden semicircle G on (1, phi^2):", construct_three_means(1, PHI**2).geometric_mean)

        # Book IV.1: Pappus's Parallelogram Area Theorem (13 + 15 = 28)
        area = construct_pappus_area_theorem(preset="scalene")
        print(area.area_ab, area.area_ac, area.area_bc, verify_pappus_area_symbolic())

        # Book IV.14-18: Infinite Arbelos tangent circle chain (y_n = n * d_n)
        arb = construct_pappus_arbelos_chain(2, 1, 4)
        print([(c.index, c.height, c.diameter, c.height_over_diameter) for c in arb.chain])
        print("Symbolic arbelos residuals:", verify_arbelos_chain_symbolic())

        # Book V.1 & Book VIII.23: Honeycomb isoperimetry & 7-hexagon circumradius R = s_6 * sqrt(7)
        hon = verify_honeycomb_isoperimetry(12, build_model=True)
        print("Tiling n-gons:", hon.tiling_polygons, "Areas:", hon.areas)
        print("7-hexagon radius:", hon.circumradius_seven_hexagons)  # 2*sqrt(7)

Cross-Ratios, Complete Quadrilateral & Golden Sections¶

import sympy as sp
        from geometor.pappus import (
            PHI,
            construct_harmonic_fourth,
            construct_pappus_hexagon,
            cross_ratio,
            find_golden_sections,
        )

        # Straightedge fourth harmonic conjugate: (A, B; C, D) = -1
        quad = construct_harmonic_fourth()
        print("Fourth harmonic D:", (quad.d.x, quad.d.y), "CR =", quad.cross_ratio_value)

        # Golden chain & harmonic-golden identity in Q(phi)
        pts = [sp.Point(t, 0) for t in (0, 1, PHI, PHI + 1)]
        print("Golden CR:", cross_ratio(*pts))  # 1/2 + sqrt(5)/2

        gold = construct_pappus_hexagon(preset="golden")
        for gr in find_golden_sections(gold.model):
            print("Golden section:", gr.point_ids)

Command-Line Interface (pappus)¶

geometor-pappus installs the pappus console entry point with Rich tabular output:

# Build all 24 interactive SVG figures (18 projective + 6 Synagoge Books III-V & VIII)
        pappus build --synagoge

        # Inspect Synagoge Books III, IV, V & VIII exact tables (or filter: means, area, arbelos, honeycomb)
        pappus synagoge
        pappus synagoge --demo arbelos

        # Inspect single-hexagon meets, quadrances, spreads, and 8-symbol determinant
        pappus inspect --preset hexagon

        # Inspect all 6 S_3 Pappus lines and Steiner Star points (S+, S-)
        pappus inspect --preset steiner --all-permutations

        # Inspect Pascal's Hexagrammum Mysticum, bi-triangle Steiner pair, and full 60-line web
        pappus pascal --preset hexagrammum --steiner-family --full-60
        pappus pascal --preset golden_conic

        # Scan a configuration for emergent harmonic tetrads and golden sections
        pappus harmonics --preset harmonic --discover-all
        pappus harmonics --preset golden
