geometor.pappus.projective
==========================

.. py:module:: geometor.pappus.projective

.. autoapi-nested-parse::

   Exact symbolic projective invariants, cross-ratios, and harmonic/golden range scanners.

   Provides 100% exact SymPy implementations of collinear cross-ratios, central
   perspectivities (Book VII, Prop. 129 of Pappus's *Collection*), Wildberger
   quadrances and spreads, collinear harmonic range detection $(A, B; C, D) = -1$,
   and integration with :mod:`geometor.divine` for golden section discovery.

.. py:function:: project_point(center: sympy.geometry.Point, target_line: sympy.geometry.Line, pt: sympy.geometry.Point) -> sympy.geometry.Point

   Project a point from a perspective center onto a target line.

   Implements central perspectivity as studied by Pappus in *Synagoge* Book VII,
   Proposition 129.

   :param center: Center of perspectivity $O$ not lying on ``target_line``.
   :param target_line: Destination line onto which ``pt`` is projected.
   :param pt: Source point $P \ne O$.

   :returns: Exact intersection $[O P] \cap \text{target\_line}$.

   :raises ValueError: If ``pt`` coincides with ``center`` or $[O P]$ is parallel to ``target_line``.


.. py:function:: cross_ratio(pt_a: sympy.geometry.Point, pt_b: sympy.geometry.Point, pt_c: sympy.geometry.Point, pt_d: sympy.geometry.Point, *, check_collinear: bool = True) -> sympy.Expr

   Compute the exact projective cross-ratio $(A, B; C, D)$ of four collinear points.

   Uses the standard projective convention

   .. math::

      (A, B; C, D) = \frac{(u_A - u_C)(u_B - u_D)}{(u_A - u_D)(u_B - u_C)},

   where $u$ is any affine coordinate along the line carrying $A, B, C, D$.
   Under this convention, $(A, B; C, D) = -1$ iff $(C, D)$ harmonically separates
   $(A, B)$, and $(0, 1; \phi, \phi + 1) = \phi$.

   :param pt_a: First point $A$.
   :param pt_b: Second point $B$.
   :param pt_c: Third point $C$.
   :param pt_d: Fourth point $D$.
   :param check_collinear: If True, verify that $A, B, C, D$ are collinear.

   :returns: Exact simplified SymPy expression for $(A, B; C, D)$.

   :raises ValueError: If the points are not collinear or if the denominator vanishes.


.. py:function:: anharmonic_orbit(lam: sympy.Expr) -> list[sympy.Expr]

   Return the six cross-ratio values generated by permuting four collinear points.

   :param lam: Fundamental cross-ratio $\lambda = (A, B; C, D) \notin \{0, 1\}$.

   :returns: List of the 6 simplified expressions
             $[\lambda, 1/\lambda, 1 - \lambda, 1/(1 - \lambda), (\lambda - 1)/\lambda, \lambda/(\lambda - 1)]$.

.. py:function:: harmonic_conjugate_point(pt_a: sympy.geometry.Point, pt_b: sympy.geometry.Point, pt_c: sympy.geometry.Point) -> sympy.geometry.Point

   Compute the exact algebraic fourth harmonic point $D$ such that $(A, B; C, D) = -1$.

   Solves $(A, B; C, D) = -1$ along line $[A B]$ in closed symbolic form. For the
   pure straightedge geometric construction via a complete quadrilateral, see
   :func:`geometor.pappus.constructions.construct_harmonic_fourth`.

   :param pt_a: First base point $A$.
   :param pt_b: Second base point $B$.
   :param pt_c: Given third collinear point $C$ (not the midpoint of $A$ and $B$).

   :returns: Exact :class:`sympy.geometry.point.Point` $D$ satisfying $(A, B; C, D) = -1$.

   :raises ValueError: If $A, B, C$ are not distinct collinear points or $C$ is the midpoint of $AB$
       (in which case $D$ lies on the line at infinity).


.. py:function:: find_harmonic_ranges(model: geometor.model.Model, line: sympy.geometry.Line | None = None, *, include_guides: bool = False) -> list[HarmonicRange]

   Scan lines in a :class:`~geometor.model.Model` for exact collinear harmonic tetrads.

   Revives and modernizes the ``analyze_harmonics`` routine from GEOMETOR's
   original 2023 ``pappus.py`` exploration. For every candidate line carrying at
   least four points, points are sorted along the line ($P_1 < P_2 < P_3 < P_4$)
   so that each unordered harmonic tetrad is reported canonically once via the
   unique alternating separation $(P_1, P_3; P_2, P_4) = -1$.

   :param model: Geometric model to scan.
   :param line: Optional single line to inspect; if ``None``, scans all lines in ``model``.
   :param include_guides: If True, also include points and lines marked ``guide=True``.

   :returns: List of discovered :class:`HarmonicRange` records.

   Scan all lines in a :class:`~geometor.model.Model` for exact Golden Ratio sections.

   Complements :func:`geometor.divine.register_divine_hook` (which checks parent
   lines incrementally as intersection points are added) with a comprehensive
   post-construction scan across all points lying on each line in ``model``.

   :param model: Geometric model to scan.
   :param register_sections: If True, also add each discovered golden :class:`Section`
                             to ``model`` with ``classes=["golden"]``.
   :param include_guides: If True, include guide points and lines.

   :returns: List of discovered :class:`GoldenRange` records.

.. py:function:: circle_stereographic_point(t: sympy.Expr | int, *, center: sympy.geometry.Point | tuple[sympy.Expr | int, sympy.Expr | int] = (0, 0), radius: sympy.Expr | int = 1) -> sympy.geometry.Point

   Compute an exact point on $(x - x_0)^2 + (y - y_0)^2 = R^2$ via rational stereographic slope $t$.

   Uses the classical Weierstrass / stereographic parameterization from $(-R + x_0, y_0)$:

   .. math::

      P(t) = \left(x_0 + R \frac{1 - t^2}{1 + t^2},\; y_0 + R \frac{2 t}{1 + t^2}\right).

   Every $t \in \mathbb{Q}$ yields an exact rational point in $\mathbb{Q}^2$, and
   every $t \in \mathbb{Q}(\phi)$ yields an exact point in $\mathbb{Q}(\sqrt{5})^2$.

   :param t: Exact symbolic or integer stereographic parameter.
   :param center: Circle center $(x_0, y_0)$.
   :param radius: Exact positive circle radius $R$.

   :returns: Exact :class:`~sympy.geometry.point.Point` on the circle.


.. py:function:: conic_equation_through_points(points: Sequence[sympy.geometry.Point | tuple[sympy.Expr | int, sympy.Expr | int]]) -> sympy.Expr

   Construct the exact quadratic conic polynomial $C(x, y)$ through five points.

   Evaluates the $6 \times 6$ Veronese determinant

   .. math::

      \det \begin{bmatrix}
      x^2 & x y & y^2 & x & y & 1 \\
      x_0^2 & x_0 y_0 & y_0^2 & x_0 & y_0 & 1 \\
      \vdots & \vdots & \vdots & \vdots & \vdots & \vdots \\
      x_4^2 & x_4 y_4 & y_4^2 & x_4 & y_4 & 1
      \end{bmatrix}

   in the symbols ``x, y``.

   :param points: Sequence of 5 points in the plane.

   :returns: Expanded SymPy polynomial in ``x`` and ``y`` (zero iff the 5 points are
             degenerate with 4+ collinear in a way that fails to determine a unique conic).

   :raises ValueError: If ``len(points) != 5``.


.. py:function:: are_coconic(points: Sequence[sympy.geometry.Point | tuple[sympy.Expr | int, sympy.Expr | int]]) -> bool

   Return True iff all given points lie on a single conic (smooth or degenerate line-pair).

   Unifies Pappus's degenerate two-line configuration ($L_a \cdot L_b = 0$) and
   Pascal's smooth conic configuration ($A x^2 + B x y + C y^2 + D x + E y + F = 0$)
   via the rank of the $N \times 6$ Veronese matrix $[x_k^2, x_k y_k, y_k^2, x_k, y_k, 1]$.

   :param points: Sequence of planar points (any $\le 5$ points trivially lie on at least one conic).

   :returns: ``True`` if the Veronese matrix has rank $\le 5$, else ``False``.


.. py:function:: conic_cross_ratio(p1: sympy.geometry.Point, p2: sympy.geometry.Point, p3: sympy.geometry.Point, p4: sympy.geometry.Point, observer: sympy.geometry.Point) -> sympy.Expr

   Compute Michel Chasles's projective cross-ratio $(P_1, P_2; P_3, P_4)_{\mathcal{C}}$ on a conic.

   By Chasles's Theorem, for four distinct points $P_1, P_2, P_3, P_4$ on an irreducible
   conic $\mathcal{C}$, the cross-ratio of the pencil of four rays
   $[V P_1], [V P_2], [V P_3], [V P_4]$ cut by any transversal line is **independent**
   of the fifth point $V = \text{observer} \in \mathcal{C}$.

   :param p1: First conic point.
   :param p2: Second conic point.
   :param p3: Third conic point.
   :param p4: Fourth conic point.
   :param observer: Distinct fifth point $V$ on the same conic.

   :returns: Exact simplified SymPy cross-ratio expression (or ``sp.oo``).

   :raises ValueError: If the 5 points are not distinct or not coconic.
