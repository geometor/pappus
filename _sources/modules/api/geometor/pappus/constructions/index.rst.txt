geometor.pappus.constructions
=============================

.. py:module:: geometor.pappus.constructions

.. autoapi-nested-parse::

   Symbolic DAG constructions for Pappus's Hexagon Theorem, Steiner's six-line configuration, and harmonic conjugates.

   Builds exact :class:`~geometor.model.Model` instances for:

   - **Pappus's Hexagon Theorem** (*Synagoge* Book VII, Props. 138 & 139): both the
     parallel-carrier case and the general projective case, plus the inscribed/perspective
     ``square`` / ``circle`` / ``diamond`` type triangles from ``pappus-3.py``.
   - **The Full $S_3$ Six-Permutation Configuration**: all six Pappus lines generated by
     permuting $B_0, B_1, B_2$, proving and constructing their 3-fold concurrencies at
     the two **Steiner (Star) points** :math:`S_+` (even permutations :math:`A_3`) and :math:`S_-`
     (odd permutations :math:`S_3 \setminus A_3`) together with the Steiner line :math:`[S_+ S_-]`.
   - **Straightedge Fourth Harmonic Conjugate**: complete quadrilateral construction of
     $D$ satisfying $(A, B; C, D) = -1$ using straightedge incidence alone.
   - **Universal Symbolic Proof**: exact polynomial identity verification over
     $\mathbb{Q}(a_0, a_1, a_2, b_0, b_1, b_2, m, c)$ via SymPy.

.. py:function:: construct_pappus_hexagon(model: geometor.model.Model | None = None, a_points: Sequence[PointInput] | None = None, b_points: Sequence[PointInput] | None = None, perm: Sequence[int] = (0, 1, 2), *, preset: str = 'hexagon', include_apex: bool = True, include_hexagon: bool = True, include_type_triangles: bool = False, discover_all_intersections: bool = False) -> PappusHexagonResult

   Construct Pappus's Hexagon Theorem for a single permutation $\sigma \in S_3$.

   Given collinear triples $(A_0, A_1, A_2)$ on line $a$ and $(B_0, B_1, B_2)$ on
   line $b$, pairs vertices according to $\sigma = (\sigma_0, \sigma_1, \sigma_2)$
   to form the hexagon $(A_0, B_{\sigma_1}, A_2, B_{\sigma_0}, A_1, B_{\sigma_2})$
   and constructs the three opposite-side cross-join meets:

   - $M_{01} = [A_0 B_{\sigma_1}] \cap [A_1 B_{\sigma_0}]$
   - $M_{12} = [A_1 B_{\sigma_2}] \cap [A_2 B_{\sigma_1}]$
   - $M_{20} = [A_2 B_{\sigma_0}] \cap [A_0 B_{\sigma_2}]$

   Handles both intersecting carrier lines (*Synagoge* VII.139) and parallel
   carrier lines (*Synagoge* VII.138), as well as configurations where one pair
   of opposite cross-joins is parallel (meeting on the projective line at infinity).

   :param model: Optional existing :class:`~geometor.model.Model`; created if ``None``.
   :param a_points: Optional sequence of 3 points on line $a$; defaults to ``preset``.
   :param b_points: Optional sequence of 3 points on line $b$; defaults to ``preset``.
   :param perm: Permutation of ``(0, 1, 2)`` ordering the $B$-points.
   :param preset: Preset key used when ``a_points`` or ``b_points`` is ``None``.
   :param include_apex: If True and $a \nparallel b$, add $O = a \cap b$ to ``model``.
   :param include_hexagon: If True, register the 6-cycle hexagon polygon in ``model``.
   :param include_type_triangles: If True, construct the ``square``, ``circle``, and
                                  ``diamond`` triangles reviving GEOMETOR's ``pappus-3.py`` exploration.
   :param discover_all_intersections: If True, add all remaining line-line intersections.

   :returns: Populated :class:`PappusHexagonResult`.


.. py:function:: construct_pappus_configuration(model: geometor.model.Model | None = None, a_points: Sequence[PointInput] | None = None, b_points: Sequence[PointInput] | None = None, *, preset: str = 'steiner', include_apex: bool = True, discover_all_intersections: bool = False, scan_harmonics: bool = True, enable_divine: bool = False) -> PappusConfigurationResult

   Construct the complete $S_3$ six-permutation Pappus–Steiner configuration.

   Generates all 9 cross-join lines $[A_i B_j]$, all 18 cross-join meets ``M{i1}{j1}{i2}{j2}``,
   all 6 Pappus lines ($3$ even in $A_3$ and $3$ odd in $S_3 \setminus A_3$), and
   constructs the two **Steiner (Star) points**:

   - :math:`S_+` (ID ``"S1"``): common concurrency point of the 3 even Pappus lines.
   - :math:`S_-` (ID ``"S2"``): common concurrency point of the 3 odd Pappus lines.

   Also constructs the Steiner line :math:`[S_+ S_-]` when both star points are finite
   and distinct, and scans the resulting configuration for collinear harmonic
   ranges and golden sections.

   :param model: Optional existing :class:`~geometor.model.Model`; created if ``None``.
   :param a_points: Optional sequence of 3 points on line $a$; defaults to ``preset``.
   :param b_points: Optional sequence of 3 points on line $b$; defaults to ``preset``.
   :param preset: Preset key used when ``a_points`` or ``b_points`` is ``None``.
   :param include_apex: If True and $a \nparallel b$, add $O = a \cap b$ to ``model``.
   :param discover_all_intersections: If True, register all pairwise intersections of
                                      carrier lines, cross-lines, and Pappus lines in ``model``.
   :param scan_harmonics: If True, populate ``harmonic_ranges`` via :func:`find_harmonic_ranges`.
   :param enable_divine: If True, attach :mod:`geometor.divine` hook and scan golden sections.

   :returns: Populated :class:`PappusConfigurationResult`.


.. py:function:: construct_harmonic_fourth(model: geometor.model.Model | None = None, pt_a: PointInput = (0, 0), pt_b: PointInput = (4, 0), pt_c: PointInput = (sp.Rational(4, 3), 0), *, apex: PointInput | None = None, relay: PointInput | None = None) -> HarmonicFourthResult

   Construct the fourth harmonic conjugate $D$ of $C$ with respect to $(A, B)$ by straightedge alone.

   Executes the classical **complete quadrilateral** construction (already implicit
   in Pappus's *Synagoge* Book VII harmonic lemmas):

   1. Choose an auxiliary apex $P$ not on $[A B]$ and join $[P A]$, $[P B]$, $[P C]$.
   2. Choose an auxiliary relay point $Q$ on $[P C]$ distinct from $P$ and $C$.
   3. Draw $[A Q]$ to meet $[P B]$ at $R$, and draw $[B Q]$ to meet $[P A]$ at $S$.
   4. Draw the diagonal $[R S]$; its intersection $D = [R S] \cap [A B]$ satisfies
      $(A, B; C, D) = -1$ **independently** of the choices of $P$ and $Q$.

   :param model: Optional existing :class:`~geometor.model.Model`; created if ``None``.
   :param pt_a: First base point $A$.
   :param pt_b: Second base point $B$.
   :param pt_c: Third collinear point $C$ (distinct from $A$, $B$, and the midpoint of $AB$).
   :param apex: Optional off-line apex $P$; chosen automatically with clean exact coordinates if ``None``.
   :param relay: Optional point $Q$ on $[P C]$; defaults to the exact midpoint of $P$ and $C$.

   :returns: Populated :class:`HarmonicFourthResult`.

   :raises ValueError: If $A, B, C$ are invalid or if $C$ is the Euclidean midpoint of $AB$.


.. py:function:: verify_pappus_symbolic() -> sympy.Expr

   Prove Pappus's Hexagon Theorem universally over a symbolic function field.

   Parameterizes carrier line $a$ as $y = 0$ with $A_i = (a_i, 0)$ and carrier
   line $b$ as $y = m x + c$ with $B_j = (b_j, m b_j + c)$ over eight independent
   symbolic indeterminates $(a_0, a_1, a_2, b_0, b_1, b_2, m, c)$ (covering both
   intersecting lines $m \ne 0$ and parallel lines $m = 0, c \ne 0$). Computes the
   homogeneous coordinates of $M_{01}, M_{12}, M_{20}$ and simplifies their $3 \times 3$
   collinearity determinant, confirming it vanishes identically ($0$).

   :returns: Simplified determinant expression (identically ``sp.Integer(0)``).
