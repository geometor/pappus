Proposition 10: Equiangular Polygon Maximizes Area
==================================================

.. rubric:: *Synagoge* Book V, Props. 7–10 (:cite:`Hultsch I, pp. 326–336 <hultsch:1876>`; App. IV, p. 1238) · Original English Translation

.. folio:: 0250
   :page: 1238

.. enunciation::

   Among equilateral rectilinear polygons of equal perimeter and the same number of sides, that which is **equiangular** encloses a strictly **greater area** than one that is not equiangular—completing the strict extremal chain:

   .. math::

      \operatorname{Area}(\text{irregular } n\text{-gon}) < \operatorname{Area}(\text{regular } n\text{-gon}) < \operatorname{Area}(\text{regular } (n+1)\text{-gon}) < \operatorname{Area}(\text{circle}).
