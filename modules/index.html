geometor.pappus¶

Pappus of Alexandria’s Synagoge (Mathematical Collection) and symbolic projective geometry.

Unifies two complementary layers in a single package:

  1. Exact Classical & Projective Constructions (geometor.pappus.synagoge_demos, geometor.pappus.constructions, geometor.pappus.pascal, geometor.pappus.projective): SymPy and geometor.model constructions spanning Book III’s three classical means in one semicircle, Book IV’s Area Theorem and infinite Arbelos tangent circle chain (\(y_n = n d_n\)), Book V’s hexagonal honeycomb isoperimetry, Book VII’s Hexagon Theorem (Synagoge VII.138 & 139), Steiner’s six-line configuration \((S_+, S_-)\), and Blaise Pascal’s 60-line Hexagrammum Mysticum (1640).

  2. Multi-Track *Synagoge* Book Codex Infrastructure (geometor.pappus.sphinx_ext): Sphinx companion-track registration (-en, -el, -summary, -notes) and offline cross-codex intersphinx wiring for photon_platform.publish.

geometor.pappus.construct_harmonic_fourth(model: geometor.model.Model | None = None, pt_a: PointInput = (0, 0), pt_b: PointInput = (4, 0), pt_c: PointInput = (sp.Rational(4, 3), 0), *, apex: PointInput | None = None, relay: PointInput | None = None) → HarmonicFourthResult¶

Construct the fourth harmonic conjugate \(D\) of \(C\) with respect to \((A, B)\) by straightedge alone.

Executes the classical complete quadrilateral construction (already implicit in Pappus’s Synagoge Book VII harmonic lemmas):

  1. Choose an auxiliary apex \(P\) not on \([A B]\) and join \([P A]\), \([P B]\), \([P C]\).

  2. Choose an auxiliary relay point \(Q\) on \([P C]\) distinct from \(P\) and \(C\).

  3. Draw \([A Q]\) to meet \([P B]\) at \(R\), and draw \([B Q]\) to meet \([P A]\) at \(S\).

  4. Draw the diagonal \([R S]\); its intersection \(D = [R S] \cap [A B]\) satisfies \((A, B; C, D) = -1\) independently of the choices of \(P\) and \(Q\).

Parameters:

  • model – Optional existing Model; created if None.

  • pt_a – First base point \(A\).

  • pt_b – Second base point \(B\).

  • pt_c – Third collinear point \(C\) (distinct from \(A\), \(B\), and the midpoint of \(AB\)).

  • apex – Optional off-line apex \(P\); chosen automatically with clean exact coordinates if None.

  • relay – Optional point \(Q\) on \([P C]\); defaults to the exact midpoint of \(P\) and \(C\).

Returns:

Populated HarmonicFourthResult.

Raises:

ValueError – If \(A, B, C\) are invalid or if \(C\) is the Euclidean midpoint of \(AB\).

Construct the complete \(S_3\) six-permutation Pappus–Steiner configuration.

Generates all 9 cross-join lines \([A_i B_j]\), all 18 cross-join meets M{i1}{j1}{i2}{j2}, all 6 Pappus lines (\(3\) even in \(A_3\) and \(3\) odd in \(S_3 \setminus A_3\)), and constructs the two Steiner (Star) points:

  • \(S_+\) (ID "S1"): common concurrency point of the 3 even Pappus lines.

  • \(S_-\) (ID "S2"): common concurrency point of the 3 odd Pappus lines.

Also constructs the Steiner line \([S_+ S_-]\) when both star points are finite and distinct, and scans the resulting configuration for collinear harmonic ranges and golden sections.

geometor.pappus.construct_pappus_hexagon(model: geometor.model.Model | None = None, a_points: Sequence[PointInput] | None = None, b_points: Sequence[PointInput] | None = None, perm: Sequence[int] = (0, 1, 2), *, preset: str = 'hexagon', include_apex: bool = True, include_hexagon: bool = True, include_type_triangles: bool = False, discover_all_intersections: bool = False) → PappusHexagonResult¶

Construct Pappus’s Hexagon Theorem for a single permutation \(\sigma \in S_3\).

Given collinear triples \((A_0, A_1, A_2)\) on line \(a\) and \((B_0, B_1, B_2)\) on line \(b\), pairs vertices according to \(\sigma = (\sigma_0, \sigma_1, \sigma_2)\) to form the hexagon \((A_0, B_{\sigma_1}, A_2, B_{\sigma_0}, A_1, B_{\sigma_2})\) and constructs the three opposite-side cross-join meets:

  • \(M_{01} = [A_0 B_{\sigma_1}] \cap [A_1 B_{\sigma_0}]\)

  • \(M_{12} = [A_1 B_{\sigma_2}] \cap [A_2 B_{\sigma_1}]\)

  • \(M_{20} = [A_2 B_{\sigma_0}] \cap [A_0 B_{\sigma_2}]\)

Handles both intersecting carrier lines (Synagoge VII.139) and parallel carrier lines (Synagoge VII.138), as well as configurations where one pair of opposite cross-joins is parallel (meeting on the projective line at infinity).

Parameters:

  • model – Optional existing Model; created if None.

  • a_points – Optional sequence of 3 points on line \(a\); defaults to preset.

  • b_points – Optional sequence of 3 points on line \(b\); defaults to preset.

  • perm – Permutation of (0, 1, 2) ordering the \(B\)-points.

  • preset – Preset key used when a_points or b_points is None.

  • include_apex – If True and \(a \nparallel b\), add \(O = a \cap b\) to model.

  • include_hexagon – If True, register the 6-cycle hexagon polygon in model.

  • include_type_triangles – If True, construct the square, circle, and diamond triangles reviving GEOMETOR’s pappus-3.py exploration.

  • discover_all_intersections – If True, add all remaining line-line intersections.

Returns:

Populated PappusHexagonResult.

geometor.pappus.verify_pappus_symbolic() → sympy.Expr¶

Prove Pappus’s Hexagon Theorem universally over a symbolic function field.

Parameterizes carrier line \(a\) as \(y = 0\) with \(A_i = (a_i, 0)\) and carrier line \(b\) as \(y = m x + c\) with \(B_j = (b_j, m b_j + c)\) over eight independent symbolic indeterminates \((a_0, a_1, a_2, b_0, b_1, b_2, m, c)\) (covering both intersecting lines \(m \ne 0\) and parallel lines \(m = 0, c \ne 0\)). Computes the homogeneous coordinates of \(M_{01}, M_{12}, M_{20}\) and simplifies their \(3 \times 3\) collinearity determinant, confirming it vanishes identically (\(0\)).

Returns:

Simplified determinant expression (identically sp.Integer(0)).

Construct Pappus’s Area Theorem (Synagoge Book IV, Prop. 1, Hultsch I, pp. 176–179).

Given an arbitrary counter-clockwise triangle \(\triangle ABC\) and two arbitrary outward parallelograms \(ABDE\) (with \(D = B + \vec{u}\), \(E = A + \vec{u}\)) and \(ACFG\) (with \(F = C + \vec{v}\), \(G = A + \vec{v}\)):

  1. Extend outer sides \([DE]\) and \([FG]\) to meet at \(H\).

  2. Join \([HA]\) and extend it across base \([BC]\) to meet \([BC]\) at \(J\).

  3. Translate segment \(HA\) to \(BL\) and \(CM\) (\(L = B + (A - H)\), \(M = C + (A - H)\)) forming outward parallelogram \(BCML\) on base \(BC\).

  4. By shear-invariance through parallels \([DE] \parallel [AB]\), \([FG] \parallel [AC]\), and \([HA] \parallel [BL] \parallel [CM]\):

    \[\operatorname{Area}(ABDE) = \operatorname{Area}(ABLH\text{-shear}) = \operatorname{Area}(BLNJ), \quad \operatorname{Area}(ACFG) = \operatorname{Area}(JCMN),\]

    whence \(\operatorname{Area}(BCML) = \operatorname{Area}(ABDE) + \operatorname{Area}(ACFG)\).
